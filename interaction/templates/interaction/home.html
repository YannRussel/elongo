Comment utiliser l’application ?

Le parcours est volontairement simple : créer un enfant, garder son code, puis revenir avec ce code pour suivre son évolution.

1

Créer un enfant

Le parent renseigne les informations de base. L’application génère ensuite un code unique à conserver.

2

Conserver le code

Ce code sert de clé d’accès. Il remplace la liste publique d’enfants et garantit un suivi plus simple et plus discret.

3

Suivre et évaluer

En entrant le code, le parent accède à la fiche de l’enfant, à l’historique des évaluations et aux rubriques disponibles.

Esprit de la plateforme

Une application rassurante, lisible et professionnelle

L’objectif est de proposer une expérience proche d’un outil sérieux d’accompagnement et d’aide, avec une présentation digne d’une structure de santé.

Accès simple

Le parent n’a pas besoin d’un compte complexe. Le code suffit pour retrouver l’enfant.

Suivi fluide

Les évaluations sont organisées par rubrique pour rendre la compréhension plus claire.

Présentation premium

Le design met en confiance et donne à l’application une image sérieuse et moderne.
