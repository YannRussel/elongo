Ce qu’il faut savoir

L’application ne présente pas de liste générale d’enfants aux parents. Le suivi se fait uniquement grâce au code personnel généré après création.

1. Un code sera généré automatiquement

Après validation, un code du type ENF-XXXXXXXX sera attribué à l’enfant.

2. Conservez bien ce code

Notez-le quelque part ou copiez-le. Il servira à retrouver la fiche de l’enfant plus tard.

3. Le suivi se fera avec ce code

Depuis l’accueil, il suffira d’entrer le code pour revoir l’enfant et lancer des évaluations.
